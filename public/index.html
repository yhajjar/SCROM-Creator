Supported Question Types JSON Specifications

Exact JSON structures and presets matching your target assessment schema.

multiple_choice

Single selection. Requires items: [{ order, text, correct }] with 1 item marked correct: true.

multiple_response

Multi-select checkboxes. Requires items: [{ order, text, correct }] with 1+ correct items.

sequence

Order ranking. Requires items: [{ order, text }] in exact chronological order.

matching

Pair matching. Requires items: [{ order, text, target, target_order }].

word_bank

Fill-in-the-blanks using body: "Start with {{term}}..." with optional distractors.

categorization

Grouping. Requires categories: [{ title }] and items: [{ text, category }].
